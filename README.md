# Cloud Store - متجر إلكتروني متكامل

## 🛒 وصف المشروع
Cloud Store هو متجر إلكتروني متكامل مبني بـ Angular 18 مع تصميم مشابه لأمازون. يحتوي على جميع الميزات المطلوبة للتجارة الإلكترونية.

## ✨ الميزات الرئيسية

### 🔐 نظام المصادقة
- ✅ تسجيل حساب جديد
- ✅ تسجيل الدخول
- ✅ دخول كضيف
- ✅ نسيان كلمة المرور
- ✅ تأكيد الإيميل (مطلوب بعد التسجيل)

### 🛍️ إدارة المنتجات
- ✅ عرض المنتجات مع الصور والأسعار
- ✅ تصنيف المنتجات حسب الفئات
- ✅ عرض العلامات التجارية
- ✅ البحث في المنتجات
- ✅ ترتيب المنتجات (السعر، الاسم)

### ❤️ قائمة الأمنيات
- ✅ إضافة/إزالة المنتجات من قائمة الأمنيات
- ✅ أيقونة القلب تتغير لونها عند الإضافة
- ✅ عرض قائمة الأمنيات

### 🛒 عربة التسوق
- ✅ إضافة المنتجات للعربة
- ✅ تعديل الكمية
- ✅ إزالة المنتجات
- ✅ حساب المجموع الكلي

### 💳 نظام الدفع
- ✅ إدخال عنوان الشحن
- ✅ خيارات الدفع (بطاقة ائتمان، دفع عند الاستلام)
- ✅ معالجة الدفع الآمن

### 📱 التصميم المتجاوب
- ✅ يعمل على جميع الشاشات (موبايل، تابلت، ديسكتوب)
- ✅ تصميم حديث وجذاب
- ✅ واجهة مستخدم سهلة الاستخدام

## 🚀 كيفية التشغيل

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### خطوات التشغيل

1. **تثبيت التبعيات:**
```bash
npm install
```

2. **تشغيل الخادم:**
```bash
npm start
```

أو استخدم الملف المساعد:
```bash
./start.sh
```

3. **فتح المتصفح:**
افتح المتصفح واذهب إلى: `http://localhost:4200`

## 🔧 التقنيات المستخدمة

- **Angular 18** - إطار العمل الرئيسي

- **Bootstrap 5** - للتصميم المتجاوب

## 📝 ملاحظات مهمة

1. **التسجيل مطلوب:** يجب إنشاء حساب قبل التسجيل الدخول
2. **تأكيد الإيميل:** مطلوب بعد التسجيل
3. **الدخول كضيف:** متاح بدون تسجيل
4. **التصميم المتجاوب:** يعمل على جميع الأجهزة

## 🐛 استكشاف الأخطاء

إذا واجهت مشاكل:

1. تأكد من تثبيت Node.js
2. احذف `node_modules` وأعد التثبيت:
```bash
rm -rf node_modules
npm install
```
3. تأكد من أن المنفذ 4200 متاح
4. تحقق من الأخطاء في وحدة التحكم
